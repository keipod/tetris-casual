# 포켓몬 잡기 2 — Design

경로: `casual/catch2/`  
허브: 포켓몬 잡기 2

## 한 줄

타일맵 초원을 탐험하다 조우하면, Three.js 3D 배틀 또는 타입 카드 승부로 포획한다.

## 확정 룰

- 성별 선택 → 스타터(이상해씨/파이리/꼬부기) → 필드
- 파티 6, 초과분은 박스. 세이브 `catch2_save_v1` (잡기1과 비공유)
- 긴 풀 조우 → 배틀 / 카드 승부 선택
- 배틀: 싸운다/가방(볼)/포켓몬/도망, 라이트 턴제, 타입 상성·STAB
- 카드: 타입 상성×전투력 비교 후 승리 시 포획
- 전투 연출: 타워식 Three.js 초원 + 주인공 뒷모습, 비네트·모션블러
- 에셋: airouter bake, 런타임 생성 비의존

## 기술

- 필드 2D 캔버스 타일맵 / 전투 Three.js (WebGL 실패 시 2.5D 폴백)
- PokeAPI 스프라이트·타입·종족값
- `serve.py` `/api/airouter` 프록시 (bake 스크립트는 직접 airouter)
