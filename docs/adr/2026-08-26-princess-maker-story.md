# ADR: 공주 이야기 → Princess Maker 2 지향 육성 시뮬

## Context
기존 `casual/story`는 분기형 비주얼 노벨(3편)이다. 목표는 Gainax *Princess Maker 2* 스타일 육성:
월/계절 스케줄, 스탯, 수업·알바·탐험·휴식, 행사(파티/전쟁/예술), 펫, 다양한 일상 이벤트, 스탯 기반 엔딩.

## Decision
`casual/story`를 **처음부터 육성 코어로 재작성**한다. 기존 배경/초상 에셋과 VN 연출은 이벤트 레이어로 재사용한다.
다른 에이전트 작업 파일(`catch2`, `tcg`, `ports.json` 등)은 건드리지 않는다.

### Phase 1 (이번 구현)
- 나이 10→14, 연 4계절 × 활동 3칸
- 스탯: 체력·힘·지력·품위·매력·도덕·신앙·감성 + 스트레스 + 금화 + 유대
- 스킬: 검술·미술·무용·요리·마법
- 평판: 무예 / 예술 / 사교 / 학문
- 활동: 수업·알바·탐험·휴식·펫돌보기
- 가을 축제: 시합 / 무도회 / 미술전 / 요리대회 중 택1
- 랜덤·고정 이벤트 VN (일상·파티·전쟁·예술·펫·수업)
- localStorage 세이브, 스탯 기반 엔딩 6종+

### 의도적 생략 (Phase 2+)
- 성인 직종, 도망/연애 디테일 풀세트, 상점·장비 전체, Cube 조언 AI, 8년×12개월 풀캘린더

## Consequences
- 허브 타이틀/설명은 “공주를 키워요”로 변경 가능하나 `ports.json`은 타 에이전트 소유 → Phase1에서는 story 내부 카피만 변경
- 구 VN 3편 데이터는 `stories-legacy.js`로 보관하거나 이벤트 시나리오로 이식
