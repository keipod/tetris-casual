# Pokémon assets (local)

런타임 공식 일러스트는 계속 **PokeAPI CDN**을 씁니다.  
여기에는 게임에 bake해 둔 **로컬 전용** 조각만 모았습니다.

| 경로 | 출처 | 내용 |
|------|------|------|
| `characters/overworld/` | catch2 | 남/여 워크·방향, shopkeep |
| `characters/portraits/` | `assets/characters/` | male/female/princess/동물 |
| `tiles/` | catch2 | grass, water, house, shop… |
| `ui/` | catch2 | fireball, coin, pokeball, sparkle |
| `combat/lanes/` | lanes | 유닛 슬롯·요새 등 PNG |
| `combat/catch/` | catch | 필드 UI PNG |

새 포켓몬 게임은 CDN 아트 + 이 폴더의 트레이너/타일/UI를 조합하면 됩니다.
