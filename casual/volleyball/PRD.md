# PRD — 피카츄 배구

경로: `casual/volleyball/`  
허브 카드명: 피카츄 배구  
담당: 구현 에이전트 (이 문서만 근거)

## 한 줄

터치·드래그로 피카츄가 **좌우 이동 + 점프**하고, **드래그 길이가 점프 힘**이 되는 해변 배구.

## 목표

- 조작감이 게임의 전부다. “드래그 정도 ∝ 점프 정도”를 한 번에 이해하게 만든다.
- 피카츄(플레이어) vs CPU 피카츄/다른 포켓몬 1:1 배구.
- PokeAPI 스프라이트 + 피카츄 울음. 한국어 UI, 모바일 터치.

## 하지 말 것

- 실제 배구 규칙 전부 (로테이션, 세트 점수 25점 등). v1은 짧은 랠리.
- 물리 엔진 라이브러리 필수화. 2D 캔버스 + 단순 적분으로 충분.
- 3D.
- 탭 한 번에 최대 점프. 그건 이 게임의 실패 조건이다.

## 조작 (반드시)

화면을 누른 채 드래그한다.

- **수평 성분** → 착지/공중 좌우 이동 방향과 속도.
- **수직 성분(주로 위로 당김, 또는 아래로 당겨 반대 점프)** → 점프 impulse.
- **드래그 거리** `dist`를 `minJump..maxJump`에 맵핑. 짧은 flick = 작은 홉, 길게 당김 = 높은 점프.
- pointerdown만 하고 거의 안 움직이면 점프하지 않거나 제자리 tiny hop (임계값 `DRAG_THRESHOLD` ≈ 14px, 버블슈터와 같은 실수 방지).
- pointerup 순간에 점프가 나간다 (차징). 누르는 동안 조준 화살표/고스트를 보여 준다.
- 공중에 있는 동안 두 번째 점프는 없음. 착지 후 다시 드래그.
- 공 근처에서 점프 타이밍이 맞으면 스파이크/토스 (점프 중 히트박스).

알 것: 사용자는 **Angry Birds/슬링샷처럼 당긴 만큼 뛰는 것**을 원한다. 고정 점프 높이 + 좌우만 바꾸면 실패다.

## 경기

- 코트: 좌우 반, 중앙 네트. 2D 사이드뷰.
- 공: 원. 중력, 네트 충돌, 바닥 바운스(한 번 이상 떨어지면 실점).
- 플레이어는 왼쪽(또는 하단 기준 자신의 코트). CPU는 반대편, 공을 따라 단순 예측 이동.
- 득점: 상대 코트에 공이 바닥에 떨어지거나, 네트 밖으로 나가면.
- 한 게임: 7점 선승, 2점 차 없이 v1은 7점 먼저.
- 서브: 득점한 쪽이 드래그로 서브.

## 비주얼

- 플레이어: PokeAPI animated Pikachu (`25.gif`) + 점프 시 back/공식 스프라이트 전환 가능.
- CPU: 다른 id (예: 7 꼬부기, 39 푸린).
- 해변/하늘 CSS 또는 캔버스. 파스텔.
- 피카츄가 공을 칠 때 cry 짧게.

## 화면 파일

`index.html`, `style.css`, `game.js`. 상단 목록/점수/사운드. 버블 `topbar` 패턴 재사용 정신만 맞출 것 (파일 복사 금지, 스타일은 배구 테마).

## 수락 기준

- [ ] 짧은 드래그 = 낮은 점프, 긴 드래그 = 높은 점프가 체감된다.
- [ ] 좌우 드래그로 이동 방향이 바뀐다.
- [ ] 탭만으로는 공을 강하게 치지 못한다.
- [ ] CPU와 랠리가 몇 번은 이어진다 (완전 무반응 CPU 금지).
- [ ] 7점 게임 종료 후 다시하기.
- [ ] 모바일에서 드래그가 스크롤로 뺏기지 않음 (`touch-action: none`).

## 검증

실기기 또는 브라우저 터치 에뮬. 드래그 길이 3단계(짧/중/장) 점프 높이 로그를 잠깐 찍어서 단조증가인지 확인 후 로그 제거.
