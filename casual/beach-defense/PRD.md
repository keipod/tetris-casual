# 비치 디펜스 — PRD

경로: `casual/beach-defense/`  
한 줄: 붐 비치풍 열대 섬에서 해안 상륙 적을 포탑으로 막아 HQ를 지키는 웨이브 TD.

## 목표

- 원맵·원세션 (웨이브 8~12), 아이소메트릭 2.5D Canvas
- 시작 골드 → 배치 단계 → 웨이브 자동 전투 → HQ HP 0이면 패배, 전 웨이브 클리어 시 승리
- 웨이브 사이 건설·업그레이드(건물당 1단계), 배속 1x/2x, 일시정지, 모바일 터치 배치

## 방어 건물 (3종)

| ID | 역할 |
|----|------|
| `mg` | 기관총 — 빠름, 단일, 저비용 |
| `cannon` | 대포 — 느림, 강함, 단일 |
| `mortar` | 박격포 — 광역, 약함, 포물선 |

## 적 (3종)

| ID | 역할 |
|----|------|
| `rifle` | 보병 — 보통 속도·HP |
| `brute` | 돌격병 — 빠름, 약함 |
| `tank` | 탱크 — 느림, 튼튼, 보상↑ |

## 비주얼·에셋

- 붐 비치 톤: 청록 바다, 모래·야자·밝은 잔디, HQ 나무+빨간 지붕
- airouter bake → `assets/` (런타임 생성 금지); 실패 시 기하 플레이스홀더로 플레이 가능
- FX: 머즐, 포물선, 피격 스파크, 처치 연기

## 기술 (Task 1 이후)

- `index.html` / `style.css` / `game.js` — 번들러 없음, Canvas 2D
- `logic.js`: 아이소 좌표, 경로·배치 검증, 경로 보간 (`MAP.path`, HQ `[8,1]`)
- 경로 웨이포인트 선분 보간, 그리드 스냅 배치, 사거리 프리뷰

## MVP 비범위

멀티맵·캠페인·세이브, 영웅/스킬, 건물 이동·회전, PvP, Three.js/WebGL, 런타임 AI 이미지.

## 성공 기준

1. 허브에서 진입 → 한 판 승/패 완주  
2. 포탑 3종·적 3종·업그레이드 1단 체감  
3. 붐 비치풍 방향성 + bake/플레이스홀더  
4. 모바일 터치 배치  
5. airouter 없이 정적 에셋으로 플레이 가능
