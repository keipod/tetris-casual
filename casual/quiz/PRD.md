# PRD — 포켓몬 도감 퀴즈

경로: `casual/quiz/`  
허브 카드명: 도감 퀴즈  
담당: 구현 에이전트 (이 문서만 근거)

## 한 줄

도감 항목에서 **이미지 / 이름 / 설명 중 틀린 것**을 고르는 퀴즈.

## 목표

- 한 화면에 포켓몬 카드처럼 보이는 항목이 나오고, 플레이어는 “이 정보가 가짜”인 축을 고른다.
- 세 축: **그림**, **이름**, **설명**. 그중 정확히 하나가 거짓말.
- PokeAPI 실데이터 + 의도적 오염.
- 한국어. 모바일.

## 하지 말 것

- 4지선다 이름 맞추기만 있는 평범한 퀴즈로 축소하지 말 것. 핵심은 **틀린 필드 찾기**.
- 매 문제 airouter 호출 (느리고 CORS). 데이터는 PokeAPI.
- 힌트 영상, 계정.

## 문제 생성

대상: 잘 알려진 종 풀 (1세대 + 버블 ROAM_IDS 합집합, 최소 40종).

한 문제:

1. 정답 종 `A`를 고른다.
2. `corrupt` ∈ {image, name, flavor} 하나를 고른다.
3. 나머지 두 필드는 `A`의 진짜 데이터.
4. 오염:
   - image: 다른 종 `B`의 official-artwork (타입이나 색이 비슷한 종 우대하면 더 좋음).
   - name: 한글 이름을 한 글자 바꾸거나, 다른 종 한글명, 또는 흔한 오역 스타일 (피카츄↔라이츄는 너무 쉽고, 비슷하게).
   - flavor: `A`의 설명을 한 문장 비틀기 (다른 종 설명을 넣거나, 타입/서식지를 반대로).

UI:

- 카드 중앙에 이미지.
- 아래 한글 이름 (크게) + 영문 (작게).
- 설명 2~3줄.
- 하단 버튼 3개: `그림이 틀림` / `이름이 틀림` / `설명이 틀림`.

피드백: 정답 축 하이라이트 + 진짜 데이터로 카드가 고쳐지는 연출. 오답이면 짧은 틀림 + 콤보 리셋.

## 진행

- 10문제 한 세트. 콤보, 점수, 최고점 localStorage `quiz_best_v1`.
- 제한시간 문제당 12초 선택(있으면 보너스). 없어도 v1 통과.
- 사운드 토글.

## 에셋

- `GET https://pokeapi.co/api/v2/pokemon/{id}`
- `GET https://pokeapi.co/api/v2/pokemon-species/{id}` → names ko, flavor_text_entries.
- 이미지: official-artwork. 로딩 스피너, 실패 시 front_default.

시작 시 10종을 prefetch. 네트워크 실패 시 한국어 에러 + 재시도.

## 화면 파일

`index.html`, `style.css`, `game.js`. 상단 목록, 점수, 사운드.

## 수락 기준

- [ ] 매 문제 세 필드 중 **하나만** 거짓이다.
- [ ] 세 종류의 오염이 세트 안에서 모두 한 번 이상 나온다.
- [ ] 정답/오답 후 무엇이 거짓이었는지 알 수 있다.
- [ ] 한글 이름·설명이 깨지지 않는다 (개행 문자 `\n` 제거).
- [ ] 허브에서 `quiz/` 진입.

## 검증

문제 생성기를 순수 함수로 두고, `window.__quiz.selfTest()`에서 “오염 축 1개” “이미지 id ≠ 이름 id when corrupt=image”를 assert.
