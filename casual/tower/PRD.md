# PRD — 파스텔 중세 타워디펜스 (Three.js / 2.5D)

경로: `casual/tower/`  
허브 카드명: 타워 디펜스  
담당: 구현 에이전트 (이 문서만 근거)

## 한 줄

중세 워크래프트3 감성의 **파스텔 타워디펜스**. 가능하면 Three.js 얕은 3D, 힘들면 **2.5D**(아이소메트릭 캔버스)로라도 한 판이 끝나게 만든다.

## 목표

- 적이 길을 따라 기지를 향해 걷는다. 타워가 때린다. 기지가 버티면 승리.
- 비주얼 키워드: Warcraft III 캠페인 맵 느낌 + 파스텔 (채도 낮지 않은 부드러운 돌·잔디·나무, 과한 고스 금지).
- 에셋은 airouter t2i로 생성해 `casual/tower/assets/`에 저장하고 게임에 박는다. 런타임 생성에 의존하지 말 것 (Pages/CORS).
- 모바일에서 타워 설치가 된다.

## 3D vs 2.5D (결정 규칙)

1. Three.js로 **지면 플레인 + 길 + 타워/적 빌보드 또는 단순 박스/캡슐** 씬이 5초 안에 뜨면 3D 채택.
2. 모델 리깅, 본, GLTF 파이프라인이 필요해지면 **즉시 2.5D로 폴백**. 저폴리 박스를 부끄러워하지 말 것.
3. 금지: Unity 이식, 복잡한 지형 스컬프트, 그림자 맵 집착.

2.5D 폴백: 캔버스 아이소메트릭 타일 + 타워/적 스프라이트. 카메라는 고정 쿼터뷰.

## 플레이

- 맵: 하나의 구불구불한 길, 시작(스폰) → 끝(기지).
- 웨이브 8~12. 웨이브 사이 준비 시간.
- 돈으로 타워 3종 건설. 업그레이드 1단계면 충분.
- 타워 종류 예:
  - 화살 탑 (단일, 빠르다)
  - 마법 탑 (광역 약함)
  - 대포 (느리고 아픔)
- 적은 골렘/오크/늑대 느낌의 파스텔 실루엣. 포켓몬을 넣지 않는 것이 테마 일관성에 좋다. (허브는 캐주얼 모음집이라 포켓몬 없어도 됨.)
- 일시정지, 배속 1x/2x.

## 에셋 생성 (airouter)

로컬에서 한 번 생성해 레포에 커밋하는 전제.

- 엔드포인트: `POST /api/airouter/v1/images/generations` (또는 직접 `http://192.168.223.101:20101/v1/images/generations`)
- 모델: `t2i_z_image_turbo_v1`
- 프롬프트 공통: `warcraft 3 style, pastel medieval, soft lighting, game asset, white background` 후 필요하면 배경 제거.
- 목록 예:
  - `path-grass.png` 타일
  - `tower-arrow.png` `tower-magic.png` `tower-cannon.png`
  - `enemy-grunt.png` `enemy-beast.png`
  - `keep.png` 기지
- 생성 실패 시 기하/그라데이션 플레이스홀더로 먼저 플레이 가능하게 한 뒤 에셋을 교체.

비전 확인이 필요하면 airouter 채팅 `qwen3-vl:8b` + data URI. 구현 필수 아님.

## 기술

- `index.html`, `style.css`, `game.js`
- 3D일 때: Three.js는 CDN ESM (`importmap`) 허용. 번들러 없이 정적 호스팅.
- path: 웨이포인트 배열. 적은 선분 따라 보간.
- 투사체: 단순 직선/포물선.

## 화면 UI

- 하단: 타워 선택, 돈, 웨이브, 기지 HP.
- 맵 빈 타일 탭 → 설치. 이미 타워가 있으면 업그레이드/판매 시트.
- 목록으로 돌아가기.
