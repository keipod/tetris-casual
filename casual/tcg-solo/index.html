승리!

보드의 카드를 모두 치웠어요

게임 설명

목표

보드에 깔린 포켓몬 카드를 모두 치우면 승리예요. 에너지가 바닥났는데 더 이상 치울 카드가 없으면 패배합니다.

카드 혼자 치우기

⚡1 → 치움!

카드를 탭해서 선택한 뒤 방출 버튼을 누르면 에너지를 써서 혼자 치울 수 있어요. 기본 카드는 ⚡1, 진화 카드는 ⚡2가 필요해요.

무료 진화 (핵심 전략!)

기본 + 진화 = 무료!

카드를 하나 선택한 뒤, 같은 진화 라인의 카드(예: 이상해씨 → 이상해풀)를 탭하면 둘 다 에너지 없이 사라져요. 어떤 카드가 어떤 카드로 진화하는지 잘 기억해두세요!

선택 바꾸기

선택한 카드와 진화 관계가 아닌 다른 카드를 탭하면 선택만 바뀔 뿐 에너지는 소모되지 않아요. 자유롭게 살펴보고 짝을 찾아보세요.
