# PRD — 포켓몬 슬라이딩 퍼즐

경로: `casual/puzzle/`  
허브 카드명: 퍼즐 맞추기  
담당: 구현 에이전트 (이 문서만 근거)

## 한 줄

포켓몬 그림을 **빈칸 슬라이딩 퍼즐**로 맞춘다. 타일은 드래그로 인접 빈칸에 미끄러져 들어간다.

## 목표

- 3×3 기본, 4×4 해금 또는 선택.
- 타일을 **클릭 점프가 아니라 드래그 슬라이드**로 옮긴다.
- 완성 시 원본 아트가 드러나고 울음 + 짧은 축하.
- 모바일에서 손가락으로  pleasuable 하게.

## 하지 말 것

- 지그소(회전·끼워맞추기) 퍼즐. 이건 15-puzzle 계열이다.
- 타일을 빈칸이 아닌 곳으로 스왑.
- 물리 엔진.

## 규칙

- 격자 N×N, 칸 하나 비움.
- 빈칸과 **변으로 인접**한 타일만 이동.
- 드래그: 타일을 빈칸 방향으로 끌면, 손가락을 따라 움직이다가 절반 이상이면 스냅 완료, 아니면 원위치.
- 클릭/탭: 인접하면 슬라이드 애니메이션으로 이동해도 된다. 다만 주 조작은 드래그.
- 섞기: 해답 있는 배치만 (빈칸을 랜덤으로 유효 이동 N회). 랜덤 순열 금지(풀 수 없는 홀짝 금지).

## 그림

- PokeAPI official-artwork를 보드에 맞게 잘라 타일 배경으로 쓴다.
- 시작 전 3초 미리보기(원본) 후 셔플.
- 우측 또는 코너에 작은 원본 미니맵.
- 종 선택: 랜덤 또는 간단한 도감 그리드(잡은 포켓몬 연동은 catch 구현 후 optional, v1은 랜덤 풀).

## 난이도

- 쉬움 3×3, 보통 4×4. 이동 수·시간 기록. best는 종+크기 키로 localStorage.

## 화면 파일

`index.html`, `style.css`, `game.js`.

## 수락 기준

- [ ] 드래그로 타일이 빈칸으로 미끄러진다.
- [ ] 대각선·원격 점프 불가.
- [ ] 모든 셔플은 해 있다 (완성 가능).
- [ ] 완성 시 빈칸이 메워지며 전체 그림 + 이름 표시.
- [ ] 3×3과 4×4.
- [ ] 허브 `puzzle/` 진입.

## 검증

`selfTest`: inversion parity, 인접 이동만 허용, 목표 상태 감지.
